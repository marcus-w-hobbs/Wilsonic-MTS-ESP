# Wilsonic MTS-ESP Manual

This is the end-user manual for Wilsonic MTS-ESP. I keep it here as plain
markdown so it lives next to the code, and the website renders these same
pages at [wilsonic.co/documentation](https://www.wilsonic.co/documentation).
If you find a mistake or a gap, please open an issue on
[GitHub Issues](https://github.com/marcus-w-hobbs/Wilsonic-MTS-ESP/issues) —
a user email about a missing explanation is what prompted this manual, and I
would rather hear about the next gap sooner.

## Chapters

1. [Quick Start](quick-start.md) — hear a scale in about a minute
2. [Which Wilsonic Is Which](which-wilsonic.md) — Wilsonic, WilsonicController, and Wilsonic for iOS
3. [Installation](installation.md) — macOS and Windows, and the MTS-ESP status indicator
4. [MTS-ESP and Your DAW](daw-setup.md) — what MTS-ESP is and how to retune your synths
5. [The Interface](interface.md) — the microtonal keyboard, the pitch wheel, and Favorites
6. [Scale Designs](scale-designs.md) — all of the scale designs, one section each
7. [Troubleshooting](troubleshooting.md) — answers to the questions I get most

## Editing

Each chapter is one markdown file, and screenshots live in
[`images/`](images/). The website fetches these files from the `main` branch
and re-renders them within an hour of a merge, so a documentation fix ships
without a website deploy.
